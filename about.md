# О проекте (AI Chat Application)

Полнофункциональное веб-приложение (SPA) для диалога с мультимодальными моделями искусственного интеллекта через OpenRouter API. Архитектура построена по методологии Feature-Sliced Design (FSD) с полной типизацией на TypeScript.

## Стек технологий

- **Core:** Vue 3 (Composition API, `<script setup>`), TypeScript, Vite 8.
- **State Management:** Pinia, `@vueuse/core` (`createGlobalState`).
- **Routing:** Vue Router 4 (динамические роуты, Navigation Guards, Role/Auth Guards).
- **Сетевой слой & API:** Axios (интерцепторы, авторизационные токены, кастомные заголовки), OpenRouter AI API (Google Gemma / multimodal LLM models).
- **Безопасность & Auth:** OAuth 2.0 PKCE Flow (RFC 7636) через нативный Web Crypto API (SHA-256, S256 code challenge).
- **Работа с файлами & Мультимодальность:** FileReader, Base64/Base64URL encoding, `URL.createObjectURL` / `revokeObjectURL` (контроль утечек памяти).
- **Архитектура:** Feature-Sliced Design (FSD).
- **UI/UX & Стили:** Модульный CSS, CSS Variables, CSS Grid (с селектором `:has()`), адаптивная вёрстка (Mobile First/Desktop), SVG-компоненты (`vite-svg-loader`), анимации (CSS keyframes).

## Опыт работы / Описание для резюме

**Frontend Developer / Vue.js Разработчик — AI Chat Application**

- **Архитектура & Стандарты:** Спроектировал и разработал масштабируемое SPA для диалога с мультимодальными LLM-моделями (OpenRouter API) по методологии **Feature-Sliced Design (FSD)** с полной типизацией на **TypeScript**.
- **Авторизация & Безопасность:** Реализовал авторизацию **OAuth 2.0 по протоколу PKCE** (Proof Key for Code Exchange) без сторонних бэкенд-прокси, используя нативный **Web Crypto API** (`SubtleCrypto` для SHA-256 хэширования, `crypto.getRandomValues`).
- **Мультимодальность & Обработка файлов:** Реализовал загрузку и передачу в модель разнородных медиафайлов (изображения, аудио, видео, PDF). Настроил конвертацию в Base64/DataURL и превью в реальном времени с оптимизацией памяти через своевременный вызов `URL.revokeObjectURL`.
- **Стейт-менеджмент & Персистентность:** Организовал архитектуру хранилищ на **Pinia**: реактивная синхронизация истории диалогов и сообщений с `localStorage` с версионированием схемы данных, оптимистичные обновления статусов сообщений (`pending`, `sent`, `error`).
- **Контекст диалога & LLM логика:** Реализовал контекстное окно чата (алгоритм обрезки последних 9 сообщений для контроля лимитов токенов модели), механизм повторной отправки (`retry`) при сетевых сбоях и повторения последнего запроса.
- **Сетевой слой:** Настроил клиент **Axios** с интерцепторами для динамического внедрения Bearer-токена авторизации и кастомных мета-заголовков.
- **UI/UX & Адаптивность:** Разработал компонентную UI-систему (кнопки, плавающий индикатор набора текста typing-dots, боковая панель с плавной анимацией сворачивания на чистом CSS Grid `:has()`, мобильное overlay-меню с `backdrop-filter`).
